# 👑 FeedbacKing

발표자와 청중을 연결하는 발표 피드백 웹 플랫폼.

> “성공이 다가 아니다. 성장이다.”

---

# 📌 프로젝트 소개

FeedbacKing은 발표자가 자신의 발표를 등록하고,  
청중이 참여 코드를 통해 발표를 평가하고 피드백을 남길 수 있는 웹사이트입니다.

발표자는:
- 별점 평균
- 항목별 평가
- 청중 피드백

을 통해 자신의 발표 능력을 객관적으로 확인하고 성장할 수 있습니다.

---

# 🎯 프로젝트 목표

- HTML / CSS / JavaScript 실력 향상

- 웹사이트 제작 과정 이해

- 발표 제목

## ⭐ 발표 피드백
청중이 발표를 평가하고 의견 작성 가능.

- 발표 총점 확인

## 🔍 검색 기능
다양한 조건으로 발표 검색 가능.

- 주제

---

## 📊 피드백 결과 확인

- 피드백 목록
