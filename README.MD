# 👑 FeedbacKing

발표자와 청중을 연결하는 발표 피드백 웹 플랫폼.

> “성공이 다가 아니다. 성장이다.”

---

# 📌 프로젝트 소개

FeedbacKing은 발표자가 자신의 발표를 등록하고,  
청중이 참여 코드를 통해 발표를 평가하고 피드백을 남길 수 있는 웹사이트입니다.

발표자는:
- 별점 평균
- 항목별 평가
- 청중 피드백

을 통해 자신의 발표 능력을 객관적으로 확인하고 성장할 수 있습니다.

# 프로젝트를 하며 느끼거나 얻은 경험
우선 git을 굉장히 능숙하게 다룰 수 있게 되었습니다. 저는 원래 git을 할때 보통 vs코드에 있는 소스제어로 git commit과 git push를 해왔었지만 이 프로젝트를 하며 git을

터미널로 할 수 있는 계기가 되었습니다. 이는 앞으로 제가 개발자가 되는데에 필수 역량이였는데 이젠 확실히 가지고있다고 생각합니다.

# git 정리
- git clone [저장소 주소 복붙] -> 클론(가져오기)
- git add .
- git commit -m "추가한것들" -> 커밋
- git push -u origin main -> 푸시(github에 전달) 
- main은 바꿀 수 있음 feature/이름 하면 브런치 생성.
- 처음 push만 잘하면 그 다음부터는 git push만 하면 알아서 해줌.
